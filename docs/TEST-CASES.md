## 通用指标定义

| 指标 | 定义 | 计算方式 |
|------|------|----------|
| Intent Routing Accuracy | 意图识别准确率 | 正确路由数/总用例数 |
| Node Output Accuracy | 节点输出正确率 | 正确输出数/总用例数 |
| Tool Selection Accuracy | 工具选择准确率 | 选对工具数/需工具用例数 |
| Tool Execution Success Rate | 工具执行成功率 | 成功执行数/调用数 |
| 参数生成正确率 | 参数完整正确率 | 参数完整用例数/总用例数 |
| Cache Hit Rate | 缓存命中率 | 命中数/请求数 |
| 幻觉率 | 编造不存在信息比例 | 幻觉回答数/总回答数 |
| Memory Recall Accuracy | 记忆召回准确率 | 召回正确数/提问数 |
| Trace Chain Completeness | Trace链完整率 | 完整trace数/总请求数 |
| 降级成功率 | 故障下不崩溃比例 | 成功降级数/故障场景数 |

## 一、Coordinator 节点（意图识别/路由）

### N1.1 正向用例（正确路由）

| # | 输入 | 期望intent | 期望路由 |
|---|------|-----------|----------|
| N1-01 | "帮我分析最近面试失败原因" | interview | Interview Agent |
| N1-02 | "Redis持久化机制有哪些" | knowledge | Knowledge Agent |
| N1-03 | "记录经验：Docker权限不足" | experience | Experience Agent |
| N1-04 | "帮我生成项目README" | document | Document Agent |
| N1-05 | "你好，今天天气怎么样" | chat | Chat Agent |
| N1-06 | "查一下项目里关于部署的资料" | knowledge | Knowledge Agent |
| N1-07 | "面试的薄弱点是什么" | interview | Interview Agent |
| N1-08 | "更新一下我的简历" | document | Document Agent |
| N1-09 | "我们踩过哪些坑" | experience | Experience Agent |
| N1-10 | "谢谢" | chat | Chat Agent |

**指标**: Intent Routing Accuracy ≥ 90%（10个全对为100%）

### N1.2 反向用例（歧义/混合意图）

| # | 输入 | 期望 | 预期行为 |
|---|------|------|----------|
| N1-11 | "帮我分析面试中Redis答得不好" | interview 或 knowledge | 两个意图混合，应选主意图（interview） |
| N1-12 | "生成README顺便记录个bug" | document 或 experience | 多意图，取第一个/主意图 |
| N1-13 | 空字符串 "" | chat | 不崩溃，兜底 chat |
| N1-14 | 纯符号 "!!!" | chat | 不崩溃，兜底 chat |
| N1-15 | 超长输入（5000字） | 不崩溃 | 正常处理或截断 |

**指标**: 多意图合理选择率、空输入兜底率

### N1.3 边界用例

| # | 输入 | 期望 | 预期行为 |
|---|------|------|----------|
| N1-16 | 只有1个字符 "好" | chat | 正常路由 |
| N1-17 | 英文 "What is Redis" | knowledge | 支持英文识别 |
| N1-18 | 代码片段 "def foo(): pass" | chat/knowledge | 不误判为document |
| N1-19 | 表情 "👍" | chat | 兜底 chat |
| N1-20 | 低置信度输入（无关词堆砌） | chat | confidence<0.4 兜底 chat |

**指标**: 英文识别率、短输入兜底率、低置信度兜底生效
